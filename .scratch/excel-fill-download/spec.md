# ดาวน์โหลด Excel และ PDF จากหน้ากรอกฟอร์ม Excel

Status: resolved

## Problem Statement

เมื่อผู้กรอก XLSX Form ต้องการสำเนาไว้ตรวจหรือส่งต่อ ปุ่มดาวน์โหลดทั้งสองจะบันทึก Draft ใน Folio ก่อนสร้างไฟล์ การขอสำเนาจึงอัปเดตทั้งคำตอบและเอกสารใน Draft แม้ผู้กรอกเพียงต้องการไฟล์จากข้อมูลที่เห็นในตัวแก้ไข

## Solution

ปรับสองปุ่มเหนือ ONLYOFFICE บนหน้ากรอก XLSX Form ให้สร้าง Excel Fill Download จากสมุดงานที่เปิดอยู่ ณ เวลากด รวมค่าที่แก้หลังบันทึก Draft ครั้งล่าสุด

| ปุ่มเดิม | ปุ่มใหม่ | ผลเมื่อกด |
| --- | --- | --- |
| บันทึกและดาวน์โหลด XLSX | ดาวน์โหลด Excel | ดาวน์โหลดสำเนาสมุดงานเป็นไฟล์ `.xlsx` |
| บันทึกและดาวน์โหลด PDF | ดาวน์โหลด PDF | ใช้การเลือกชีตและการจัดหน้าแบบปุ่ม PDF เดิม แล้วเริ่มดาวน์โหลดโดยอัตโนมัติเมื่อแปลงเสร็จ |

ตัวอย่างเกณฑ์รับงานคือบันทึกค่า `100` แล้วแก้เป็น `200` ในตัวแก้ไข ไฟล์ Excel และ PDF ต้องได้ `200` ส่วน Draft ใน Folio ต้องอ่านได้เป็น `100` จนกว่าผู้กรอกจะกด **บันทึกฉบับร่าง** อีกครั้ง

## User Stories

1. ในฐานะผู้กรอก ฉันต้องการเห็นปุ่ม **ดาวน์โหลด Excel** เพื่อรู้ว่าจะได้ไฟล์ Excel
2. ในฐานะผู้กรอก ฉันต้องการเปิดไฟล์ `.xlsx` ที่ดาวน์โหลดมาเพื่อตรวจคำตอบพร้อมโครงสร้างและรูปแบบของสมุดงาน
3. ในฐานะผู้กรอก ฉันต้องการให้ไฟล์ Excel มีค่าที่เพิ่งแก้ในตัวแก้ไข เพื่อใช้สำเนาที่ตรงกับงานปัจจุบัน
4. ในฐานะผู้กรอก ฉันต้องการให้ไฟล์ PDF ใช้ค่าล่าสุดชุดเดียวกับที่เห็นในตัวแก้ไข เพื่อส่งต่อข้อมูลปัจจุบัน
5. ในฐานะผู้กรอก ฉันต้องการให้การเลือกชีต พื้นที่พิมพ์ และการจัดหน้า PDF สอดคล้องกับปุ่มเดิม เพื่อใช้เอกสารในรูปแบบที่คุ้นเคย
6. ในฐานะผู้กรอก ฉันต้องการให้ PDF เริ่มดาวน์โหลดหลังแปลงเสร็จจากการกดปุ่มครั้งเดียว เพื่อรับไฟล์โดยตรง
7. ในฐานะผู้กรอก ฉันต้องการดาวน์โหลดได้ตั้งแต่เปิดกรอกรอบแรกเมื่อตัวแก้ไขพร้อม เพื่อเก็บสำเนาก่อนตัดสินใจบันทึก Draft
8. ในฐานะผู้กรอก ฉันต้องการให้ค่าที่เพิ่งพิมพ์ในเซลล์ติดไปกับไฟล์เมื่อกดดาวน์โหลดทันที เพื่อให้สำเนารวมคำตอบล่าสุด
9. ในฐานะผู้กรอก ฉันต้องการให้การดาวน์โหลดสร้างเฉพาะสำเนา เพื่อให้ฉันเลือกเองว่าจะบันทึกค่าปัจจุบันเป็น Draft เมื่อใด
10. ในฐานะผู้กรอก ฉันต้องการให้คำเตือนก่อนออกจากหน้าสะท้อนงานที่ยังแก้ค้างหลังดาวน์โหลด เพื่อกลับไปบันทึกได้ทัน
11. ในฐานะผู้กรอก ฉันต้องการเห็นว่าระบบกำลังเตรียมไฟล์อยู่ เพื่อแยกการรอดาวน์โหลดออกจากการรอบันทึกฉบับร่าง
12. ในฐานะผู้กรอก ฉันต้องการเห็นข้อผิดพลาดและกดดาวน์โหลดซ้ำได้ เพื่อรับไฟล์เมื่อการสร้างไฟล์ครั้งแรกไม่สำเร็จ
13. ในฐานะผู้กรอก ฉันต้องการกดปุ่มดาวน์โหลดด้วยคีย์บอร์ดและค้นหาปุ่มจากชื่อที่แสดง เพื่อใช้ทั้งสองคำสั่งได้สะดวก
14. ในฐานะเจ้าของ Response ฉันต้องการให้คำสั่งดาวน์โหลดใช้สมุดงานของ Response ที่ฉันกำลังกรอก เพื่อให้ได้ไฟล์ของคำตอบที่ถูกต้อง
15. ในฐานะผู้กรอก ฉันต้องการเลือก **บันทึกฉบับร่าง** หรือ **ส่งคำตอบ** หลังดาวน์โหลดได้ เพื่อเก็บงานหรือส่งเมื่อพร้อม

## Implementation Decisions

- ใช้ปุ่มเดิมบนหน้ากรอก XLSX Form โดยแยกคำสั่งดาวน์โหลดออกจากคำสั่งบันทึก Draft และส่งคำตอบ การดาวน์โหลดสร้างไฟล์จากตัวแก้ไข ส่วนคำสั่งบันทึก Draft เก็บคำตอบและไฟล์ฉบับร่างใน Folio
- จับสำเนาจากสมุดงานของ Response ที่เปิดอยู่ใหม่ในแต่ละคำขอ โดยใช้ session แก้ไขและสิทธิ์ของเจ้าของ Response รองรับเฉพาะ Excel และ PDF สำหรับสองปุ่มนี้
- ให้ตัวแก้ไขยืนยันค่าที่กำลังพิมพ์ลงเซลล์ตามกติกาเดิมก่อนจับสำเนา หากยืนยันค่าหรือสร้างสำเนาไม่ได้ ให้แจ้งข้อผิดพลาดการดาวน์โหลดและเปิดให้ลองใหม่กับค่าปัจจุบัน
- ปุ่ม Excel ส่งสำเนา `.xlsx` ให้ผู้กรอกโดยตรง ปุ่ม PDF ส่งสำเนา `.xlsx` ชั่วคราวเข้าเครื่องแปลงเดิมด้วยค่าการแปลงแบบปุ่มปัจจุบัน แล้วคืนไฟล์ให้ดาวน์โหลดเมื่อแปลงเสร็จ ปล่อยสำเนาชั่วคราวเมื่อแปลงเสร็จหรือคำขอสิ้นสุด
- ให้การดาวน์โหลดมีสถานะเตรียมไฟล์และข้อผิดพลาดของตัวเอง แสดงปุ่มพร้อมใช้เมื่อตัวแก้ไขพร้อมรับคำสั่ง ป้องกันคำขอซ้ำระหว่างเตรียมไฟล์ และเปิดให้ลองใหม่หลังเกิดข้อผิดพลาด
- ให้สถานะบันทึกและคำเตือนก่อนออกจากหน้าอิงการบันทึก Draft จริง การเตรียมไฟล์หรือการดาวน์โหลดสำเร็จเป็นเหตุการณ์ของการดาวน์โหลด

## Testing Decisions

- ทดสอบหลักจากหน้ากรอก XLSX Form จริงในเบราว์เซอร์ด้วยฟอร์มทดสอบและ ONLYOFFICE รุ่นที่โปรเจกต์ใช้อยู่ กดปุ่มผ่าน UI เปิดไฟล์ผลลัพธ์ และอ่าน Draft ที่เก็บใน Folio ผ่านช่องทางปกติเพื่อเทียบค่าก่อนและหลัง
- บันทึกค่า `100` แล้วแก้เป็น `200` ดาวน์โหลดทั้งสองรูปแบบและตรวจเนื้อหาไฟล์ ตรวจว่า Draft ที่เก็บไว้ยังเป็น `100` และหน้ายังแจ้งงานแก้ค้างเมื่อพยายามออก จากนั้นกด **บันทึกฉบับร่าง** และตรวจว่า Folio เก็บ `200`
- ทำกรณีค่าล่าสุดซ้ำกับการกดดาวน์โหลดขณะที่เซลล์ยังอยู่ในโหมดแก้ไขและกับ Response ที่เพิ่งเปิดกรอกรอบแรก ใช้ข้อมูลทดสอบที่ทำให้ตรวจค่าจากไฟล์ Excel และ PDF ได้ชัดเจน
- เทียบ PDF กับผลจากปุ่มเดิมเมื่อใช้สมุดงานเนื้อหาเดียวกัน ใช้ไฟล์ทดสอบที่มีหลายชีตและกำหนดพื้นที่พิมพ์หรือแนวกระดาษไว้ ตรวจว่าคลิกครั้งเดียวแล้วเบราว์เซอร์เริ่มดาวน์โหลดหลังแปลงเสร็จ
- ต่อยอดชุดทดสอบหน้ากรอก Excel เพื่อตรวจชื่อและสถานะของปุ่ม การกดด้วยคีย์บอร์ด และการแจ้งเตือนเมื่อเตรียมไฟล์หรือแปลง PDF ล้มเหลว ทดสอบการลองใหม่จากหน้ากรอกเดียวกันและอ่านค่าที่เก็บใน Draft หลังความล้มเหลว
- รัน regression สำหรับ **บันทึกฉบับร่าง** และ **ส่งคำตอบ** บนหน้า Excel รวมถึงการบันทึกแล้วดาวน์โหลดบนหน้า DOCX ทั้ง Native form และ ONLYOFFICE

## Out of Scope

- หน้ากรอก DOCX ทั้ง Native form และ ONLYOFFICE
- การดาวน์โหลดจากหน้าออกแบบ Form, Results, ประวัติ Submission และใบรับคำตอบ
- การเพิ่มชนิดไฟล์ ตัวเลือกการพิมพ์ หรือคำสั่งดาวน์โหลดในเมนูของ ONLYOFFICE
- การเปลี่ยนกติกาบันทึก Draft ส่งคำตอบ หรือแก้ไข Submission ผ่าน Correction

## Further Notes

- เริ่มลงมือด้วยการทดลองวิธีจับสำเนาในฟอร์มทดสอบ แหล่งข้อมูลของไฟล์และผลที่ผู้กรอกเห็นตกลงแล้ว ส่วนการอ่านค่าขณะเซลล์กำลังแก้ไขและการสร้างสำเนาด้วยสิทธิ์ของ session ปัจจุบันยังต้องพิสูจน์กับ ONLYOFFICE ที่รันจริง [API ส่งออกของ ONLYOFFICE](https://api.onlyoffice.com/docs/plugins/interacting-with-editors/spreadsheet-api/Methods/GetFileToDownload)
- อัปเดตคู่มือระบบพร้อมโค้ด ให้คู่มืออธิบายทางเดินดาวน์โหลดจากตัวแก้ไขแยกจากการบันทึก Draft ตรวจรายการเส้นทางของ `main` ที่ค้างอยู่ก่อนงานนี้ แล้วสร้างและตรวจคู่มือด้วยสคริปต์ workflow ของโปรเจกต์
