## Deployment and limitations

Apply `20261027000000_add_viewer_role` and regenerate Prisma before deploying. The officer-to-VIEWER transition occurs at the next successful SSO, revoking prior sessions when the effective role changes. The last enabled Admin needs another enabled Admin before a downgrade can succeed. No production data backfill, remote push or deployment was performed.

Controlled SSO tests use a test PDMS exchange; live PDMS login was not exercised. Existing result-page history/navigation behavior is reused; this work does not add a new historical-submission navigation interface. Downloaded files can naturally be edited outside Folio without changing the saved server result.
